# Machine Learning Model Evaluation and Detection

This repository contains a collection of notebooks and scripts dedicated to the training, evaluation, and application of various machine learning models, with a special emphasis on the XGBoost model.

## 📂 Directory Structure

- `detector.ipynb`: Training notebook for the XGBoost model.
- `Model Evaluation.ipynb`: Evaluation and comparison of various machine learning models.
- `dataset.csv`: Dataset used for model training.
- `predictions.csv`: Contains the prediction results from the model.
- `python_parser.py`: Script to compute model metrics and perform detection tasks using the trained model.
- `trained_xgboost_model.pkl`: Serialized trained XGBoost model.
